# como usar:

- 1 programa \<papear\> al {programa}
- 2 programas \<papear\> al {programa1} y al {programa2}
- 3 o mas programas \<papear\> al {programa1}, {programa2}, {programa3} ... y al {programa final}

## programa puede ser:
- pid: pid {numero} (ej: "papear al pid 67")
- nombre: {nombre del programa}
- nombre con comillas para cosas mas complejas: "{nombre del programa}"
